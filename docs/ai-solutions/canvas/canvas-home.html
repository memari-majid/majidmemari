Find a real-world need, select a suitable AI capability, build a useful solution without programming, test it with a person, and explain the evidence, impact, resources, and next decision. No prior AI, statistics, or business background is required.

One path, twelve units, one project

  1. Read and explore. Use Learn → Try → Build → Finish inside each Canvas lesson. Read the original explanation and the assigned free textbook passage in the embedded reader, then apply one idea to the same project. A text/table alternative, figures, simulations, and the course TA are on the page.
  2. Submit one short practice response. Read the exchange first when it appears in Units 3, 7, and 12; a supplied sample lets you continue without waiting for a peer. Then use Canvas Next for three choice questions and a zero-point project update. Read the immediate choice explanations; written feedback may await instructor review.
  3. Improve the same project. Submit five cumulative milestones. Use an approved need or the complete fictional Cedar Desk case; no partner, paid AI tool, live attendance, or public launch is required.

Suggested pace: one unit per learning block. Allow 77–135 minutes for guided unit work including the assigned reading, plus project/review time; 40–67 hours total is a provisional design estimate, not measured workload. Textbook time is included in that total. Follow current Canvas dates and allow time for feedback and an actual reviewer attempt.

Read the course guide for the routine, feedback windows, recovery options, and individual exam. Use the classroom case and editable templates throughout.

Required textbooks, free access: short assigned passages from an academic AI text, a business/value-creation text, and a statistics companion support the project. Each lesson gives the book, edition, precise scope, and reader; the guide lists the complete bibliography. No purchase or access code is required; the guide explains an honest access alternative.

Questions, feedback, and finishing

  • Course questions and project exchange: optional general questions and constructive peer help.
  • Canvas Inbox: private assessment/access questions and requests for an asynchronous classroom reviewer.
  • Course AI TA: explanations and hints inside the lesson; it cannot read Canvas submissions, grades, or private feedback.
  • Canvas Grades: instructor comments, rubrics, and reviewed results. Read and revise before treating work as complete.
  • Completion checklist: final evidence, individual exam, handoff, and pending tasks.

While the facilitated course is active, planning targets are two working days for questions and five for milestone/exam feedback; the instructor confirms these arrangements before enrollment. A view or submission tick records progress, not correctness, approval, or an award.

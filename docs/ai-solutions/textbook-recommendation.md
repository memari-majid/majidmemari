# Selective textbook recommendation

Source check: **November 11, 2026**. This is a recommendation for instructor preparation and optional study. The original core reading in Canvas remains required and sufficient; no purchase or external visit is required.

**Primary reference: Marily Nika, *Building AI-Powered Products*.** O'Reilly lists February 2025, 230 pages, and beginner-to-intermediate level. The published scope makes it the strongest single fit in the current shortlist. This is not a full-book review or adoption survey. [Publisher record and contents](https://www.oreilly.com/library/view/building-ai-powered-products/9781098152697/).

Use selected conceptual sections; Chapter 3 includes code/engineering material. Inspect a lawful copy before assigning excerpts. No page assignments or mandatory whole-book sequence are proposed.

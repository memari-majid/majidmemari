# AI Learning Companion and research preparation

November 12, 2026. Owner: Majid Memari.

The course interface now calls its learning support **AI Learning Companion**. Internal API paths, storage keys and compatibility names remain stable. The separate website guide and workshop companion retain their own data boundaries.

## Educational implementation

- Existing decision labs and the Unit 4 workflow rehearsal retain their authored facts, deterministic consequence engine, manual classification, frozen second-workflow run and complete worked routes.
- Optional message starters prefill an editable draft, focus the message control and wait for explicit sending.
- A closed-by-default **Reflect & improve** journal offers optional bounded responses, explicit same-tab save, copyable export and a scoped clear confirmation.
- Journal state is separate from lab records, conversation and workbook data. Unknown/noncanonical records are preserved for copying. Blocked storage leaves a usable writing/export route.
- Switching to Course questions preserves unsaved journal edits. Changing units with unsaved edits requires an explicit keep/discard decision. Client-ready rendering avoids native disclosure restoration causing a hydration mismatch.
- Journals are suppressed for assessment/unknown lesson contexts. Existing course support routes and academic assessment policies are unchanged.

**Research collection remains OFF.** There is no research endpoint, participant identifier, allocation, consent checkbox, event collector or journal upload. Journal responses are not appended to chat. Explicit companion requests still use the disclosed AI service; infrastructure/provider processing is separate from this private journal.

## Research ownership

The canonical course repository owns `courses/cs4720R/docs/research/`: README, prior-art/contribution review, study design, measurement plan and implementation handoff. These internal plans are not public course pages or retrieval input. They propose a reviewed/consented course-student usability pilot and an up-to-30-student feasibility comparison; actual enrollment, staffing and approvals are not established.

The minimal proposed comparison holds the authored simulation constant and varies AI versus student interpretation of written workflow steps. First-period delayed unaided novel-case reasoning is the proposed primary learning measure, with independent human scoring. Public Request C is instructional practice. Further prior-art positioning, an independently authored held-out benchmark, approved protocol, independent consent handling/coders and learner evidence remain required before publication claims.
